# Wytboard

Practise product design whiteboard interviews on a FigJam-style canvas with an AI
interviewer that talks to you, reads your board and probes your reasoning.

Wytboard is free to run: it is a static web app with no server, and each user
brings their own LLM API key, which stays in their browser.

**Status:** early development. The app shell is in place; the canvas, interviewer
and voice are still to come.

## Run it locally

```bash
npm install
npm run dev
```
